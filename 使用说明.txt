一、在 Windows 电脑打开
1. 先把整个 ZIP 解压到一个文件夹。不要在压缩软件里直接打开网页。
2. 双击“打开网页.cmd”。它使用 Windows 自带 PowerShell，在本机启动静态网页服务并打开默认浏览器；不需要 Codex、Python、Node.js 或数据接口 token。
3. 黑色窗口显示的网址就是本机入口。使用期间保持该窗口打开；关闭窗口或按 Ctrl+C 即可停止服务。
4. 服务只监听 127.0.0.1；不会把本机文件夹自动发布到公网。端口默认从 8321 开始选择可用端口。
5. 如果公司电脑限制脚本执行，可以请管理员允许这个本地脚本，或将下述静态网页文件上传到获准使用的网站服务器。

二、上传静态网站
index.html、assets、data、favicon.svg 和 .nojekyll 应保持在同一层级。可将完整解压目录作为 GitHub Pages 等静态站点的发布目录。
网站采用相对资源路径和 # 路由，共6个一级模块。研究工作台和06知识库均包含在包内；知识库下设研究专题、历史事件库、市场时间轴三个二级页面。
双击 index.html 使用 file:// 打开会受到浏览器本地 JSON 读取限制，请采用本地启动器或静态网站服务器。
